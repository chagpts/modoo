# AuditSecu Academy Full Curriculum Site

완전히 새로 만든 학원형 정적 웹사이트입니다.

## 구성
- `index.html`: 메인 학원 페이지
- `pages/*.html`: 8단계 상세 페이지와 77개 교육 내용 페이지
- `css/reset.css`, `css/style.css`: 공통 스타일
- `js/main.js`: 모바일 메뉴와 커리큘럼 검색
- `supabase-schema.sql`: 문의/게시판 연결용 선택 스키마

## 실행
로컬에서 바로 열거나, VS Code Live Server, Netlify, Vercel, GitHub Pages에 올리면 됩니다.

## 페이지 수
- 메인 1개
- 8단계 상세 8개
- 교육 내용 77개
- 총 86개 HTML 페이지
