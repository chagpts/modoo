내부회계관리 02-10 조서형 실습: 결함의 심각도 판단과 개선권고 작성

실습 개요

통제 예외가 단순 오류인지, 유의적 미비점인지, 중요한 취약점인지 판단하고 경영진 개선계획까지 조서화한다.

이 수업은 단순 개념 설명이 아니라 내부회계관리 조서의 실제 작성 흐름을 따라갑니다. 먼저 업무 프로세스와 재무제표 계정을 연결하고, 그다음 위험을 정의한 뒤, 통제목적·통제활동·담당자·빈도·증빙·테스트 절차를 하나의 조서로 완성합니다.

학습자는 감사인이 작성하는 관점과 회사 내부통제 담당자가 준비하는 관점을 함께 비교합니다. 같은 통제라도 감사인은 충분하고 적합한 증거를 요구하고, 회사는 통제가 반복 가능하게 운영되었음을 보여주어야 하므로 두 관점의 문서화 방식이 달라집니다.

회사 내부회계 담당자 관점

  • 업무흐름도와 규정에서 통제가 실제로 수행되는 지점을 표시합니다.
  • 통제 담당자, 검토자, 승인권자, 대체 담당자를 명확히 구분합니다.
  • 승인 로그, 검토 체크리스트, 시스템 출력물 등 통제 증빙의 보관 위치를 정리합니다.
  • 예외사항이 발생했을 때 수정 절차와 재검토 절차가 존재하는지 확인합니다.

외부감사인 관점

  • 통제가 재무제표 왜곡위험을 예방하거나 발견하기에 충분한지 판단합니다.
  • 모집단 완전성, 표본 선정 근거, 증빙의 신뢰성을 독립적으로 확인합니다.
  • 통제 설계평가와 운영평가를 구분하여 조서에 결론을 남깁니다.
  • 발견된 예외가 단순 오류인지, 통제 미비점인지, 유의적 미비점인지 평가합니다.

핵심 감사위험

  • 발견사항이 재무제표 왜곡가능성과 연결되지 않아 심각도 판단이 약해질 수 있음
  • 보완통제 존재 여부를 확인하지 않고 결함 등급을 단정할 수 있음
  • 개선권고가 담당자·기한·재발방지 절차 없이 선언적으로 작성될 수 있음

조서 작성 실습 절차

  1. 프로세스 이해: 담당자 인터뷰, 업무흐름도, 권한표, 관련 규정을 확인하여 실제 업무 흐름을 한 문단으로 요약합니다.
  2. 위험 식별: 발생사실, 완전성, 정확성, 기간귀속, 평가, 표시 등 재무제표 주장과 연결되는 위험을 작성합니다.
  3. 통제목적 정의: 위험 문장을 그대로 반복하지 않고, 통제가 달성해야 하는 구체적인 목적을 문서화합니다.
  4. 통제활동 기술: 누가, 언제, 어떤 자료를 기준으로, 어떤 검토를 수행하고, 어떤 증빙을 남기는지 작성합니다.
  5. 설계평가: 해당 통제가 설계상 위험을 충분히 완화하는지 판단하고 부족한 경우 보완통제를 식별합니다.
  6. 운영평가: 모집단을 정의하고 표본을 선정하여 승인, 검토, 재수행, 대사 등 테스트를 수행합니다.
  7. 결론 작성: 테스트 결과, 예외사항, 원인, 재무제표 영향, 개선권고를 한 페이지 조서로 정리합니다.

조서 템플릿 예시

구분작성 내용실습 포인트
통제 IDC-10-01프로세스, 위험, 통제번호가 추적 가능해야 합니다.
관련 계정매출, 매출채권, 재고, 매입채무, 현금및현금성자산, 결산조정 계정 중 해당 항목통제가 어떤 재무제표 라인아이템을 보호하는지 명확히 합니다.
통제 설명담당자가 시스템 보고서와 원천증빙을 비교하고 차이를 검토한 뒤 전자승인으로 결론을 남깁니다.검토했다는 표현만 쓰지 않고 검토 기준과 증빙을 함께 적습니다.
통제 빈도거래별, 일별, 주별, 월별, 분기별, 수시 중 선택운영평가 표본 수와 모집단 정의에 직접 영향을 줍니다.
증빙승인 화면 캡처, 로그 다운로드, 체크리스트, 대사표, 예외 보고서증빙이 사후 작성되지 않았는지 생성일과 승인일을 확인합니다.
테스트 절차표본을 선정하여 증빙과 시스템 기록을 대조하고 필요 시 재수행합니다.조회만으로 끝내지 않고 감사인이 같은 결론에 도달할 수 있어야 합니다.

일반 문서점검 vs 데이터 기반 점검 비교

항목일반 내부회계 조서 접근전산감사·데이터 접근
모집단 확인담당자가 제공한 리스트와 조서 첨부파일을 확인합니다.ERP 또는 DB에서 직접 추출한 전체 거래와 제공 리스트를 대사합니다.
승인 확인전자결재 화면, 이메일, 서명 파일을 표본별로 확인합니다.승인 로그의 사용자 ID, 승인시각, 변경이력을 추출하여 이상 패턴을 확인합니다.
예외 식별선정 표본에서 승인 누락, 금액 불일치, 증빙 누락을 기록합니다.전체 모집단에서 승인자 공란, 사후승인, 동일 계좌 반복, 금액 임계치 우회 거래를 탐지합니다.
결론표본 테스트 결과를 근거로 운영 효과성을 판단합니다.표본 테스트와 전체 데이터 분석 결과를 결합하여 예외의 범위와 원인을 설명합니다.

실습 데이터 필드

  • 발견사항: 승인 누락 2건
  • 관련 계정: 매출채권
  • 잠재 왜곡: 120,000,000
  • 보완통제: 월말 채권 검토
  • 등급 판단: 미비점 또는 유의적 미비점 검토

수업에서는 위 필드를 CSV 또는 엑셀 형태로 제공하고, 학습자가 직접 필터링·대사·표본선정을 수행합니다. 데이터 분석 도구를 쓰는 경우에도 최종 결론은 내부회계관리 조서 문장으로 작성해야 합니다.

수업 진행 흐름

  1. 강사가 샘플 회사의 업무흐름과 관련 계정을 설명합니다.
  2. 학습자가 위험 문장을 작성하고 통제목적과 통제활동을 분리합니다.
  3. 제공된 증빙 묶음에서 충분한 증거와 부족한 증거를 구분합니다.
  4. 표본을 선정하여 운영평가 테스트를 수행하고 예외사항을 기록합니다.
  5. 예외사항의 원인, 재무제표 영향, 보완통제 존재 여부를 토론합니다.
  6. 최종 조서에 설계평가 결론, 운영평가 결론, 개선권고를 작성합니다.

수업 산출물

미비점 평가표, 영향도 분석, 개선권고안을 완성합니다. 산출물은 포트폴리오에 넣을 수 있도록 조서 표지, 수행 절차, 테스트 결과, 발견사항, 개선권고 순서로 정리합니다.

  • 업무흐름도 또는 프로세스 요약 1페이지
  • 위험-통제 매핑표 및 RCM
  • 설계평가 체크리스트와 Walkthrough 기록
  • 운영평가 표본선정표와 테스트 결과
  • 미비점 평가 및 개선권고 문안
