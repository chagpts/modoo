01. 회계 데이터 이해

실제 회계감사 절차와 전산감사 절차를 같은 케이스에서 비교하며, 조서·데이터 요청서·예외 분석표까지 직접 작성합니다.

세부 교육 페이지

각 페이지는 일반 회계감사 실습과 전산감사 실습을 나란히 배치했습니다. 검색창에 키워드를 입력하면 하위 교육을 빠르게 찾을 수 있습니다.

01-01

재무제표와 전표 데이터 구조

재무제표 금액이 어떤 전표·원장·보조원장에서 만들어지는지 추적하고, 일반감사의 증빙 대조 방식과 전산감사의 데이터 계보 추적 방식을 나란히 실습합니다.

01-02

매출·매입 데이터 기본 검토

매출과 매입 거래를 실제 감사인이 확인하는 증빙 흐름과 전산감사인이 검증하는 데이터 흐름으로 분리해 실습합니다.

01-03

계정과목 매핑과 오류 탐지

계정과목 코드가 재무제표 표시계정으로 매핑되는 과정을 검토하고, 잘못 분류된 거래를 수기 검토와 데이터 분석으로 동시에 찾아봅니다.

01-04

일반감사 조서 작성 방식

동일한 회계 이슈를 일반감사 조서로 작성할 때 필요한 절차, 증빙, 결론 문구를 실습하고 전산감사 산출물과 어떻게 연결되는지 비교합니다.

01-05

전산감사 관점의 데이터 요청

회사가 주는 자료를 그대로 받는 방식에서 벗어나, 감사 목적에 맞는 데이터 요청서와 필드 정의서를 작성하는 실습입니다.

01-06

샘플링과 전체 모집단 분석 비교

표본감사의 논리와 전체 모집단 분석의 장단점을 같은 거래 데이터로 비교해 봅니다.

01-07

이상거래 탐색 기본 로직

감사인이 경험적으로 의심하는 거래를 데이터 규칙으로 바꿔 이상거래 탐색 로직을 설계합니다.

01-08

감사증거와 시스템 데이터 연결

종이·PDF 증빙과 ERP 원천 데이터를 연결하여 감사증거의 신뢰성과 충분성을 판단하는 실습입니다.

01-09

회계감사 시험 예제 전산화

회계감사 시험형 문제를 실제 전산감사 절차로 바꾸는 연습입니다. 서술형 답안을 데이터 요청, 테스트 로직, 조서 산출물로 전환합니다.

01-10

미니 케이스 리뷰

회계 데이터 이해 과정에서 배운 내용을 하나의 미니 감사 케이스로 통합합니다. 일반감사와 전산감사의 역할 분담, 산출물 연결, 최종 결론 작성까지 실습합니다.
