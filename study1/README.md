# AuditSecu Academy

AI 전산감사 실무 교육/학원 홈페이지 템플릿입니다.

## 실행 방법

1. 압축을 풉니다.
2. `index.html`을 브라우저로 엽니다.
3. Supabase를 연결하려면 `js/supabase-config.js`의 값을 수정합니다.
4. Supabase SQL Editor에서 `supabase-schema.sql`을 실행합니다.

## 포함 기능

- 학원형 랜딩페이지
- 과정소개 / 커리큘럼 / 강의실습 / AI 실습 데모
- 공지사항·자료실·Q&A 게시판
- 수강문의 폼
- Supabase 문의 저장 및 게시판 연동 코드
- Supabase 미설정 시 샘플 데이터 표시

## 수정할 파일

- 메인 문구: `index.html`
- 색상/폰트 변수: `css/variables.css`
- Supabase 설정: `js/supabase-config.js`
- 테이블 생성 SQL: `supabase-schema.sql`
