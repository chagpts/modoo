02. 매출·매입 데이터 기본 검토

매출과 매입 거래를 실제 감사인이 확인하는 증빙 흐름과 전산감사인이 검증하는 데이터 흐름으로 분리해 실습합니다.

실습 시나리오

분기 말 매출이 급증했고 일부 매입은 특정 공급업체에 집중되어 있습니다. 회사는 정상적인 계절성이라고 설명하지만 감사인은 매출 인식 시점과 매입 거래 실재성을 확인해야 합니다.

핵심 감사위험: 가공매출, 선인식 매출, 지연된 매입 인식, 특수관계자 거래 은폐, 공급업체 마스터 오입력 가능성입니다.

일반 회계감사 실습

감사인이 실제 조서를 작성한다는 전제로 증빙 확인, 인터뷰, 표본 검토, 결론 작성까지 수행합니다.

  • 매출 계약서, 출고증, 세금계산서, 거래명세서, 입금내역을 거래 건별로 묶어 증빙 패키지를 만듭니다.
  • 매출 상위 10건과 매입 상위 10건을 선정하고 거래처·금액·일자·승인자를 비교합니다.
  • 기말 전후 10일의 거래를 컷오프 표본으로 선정하여 출고일, 검수일, 세금계산서일, 회계처리일을 대조합니다.
  • 매입 거래는 발주서, 입고확인서, 세금계산서, 지급결의서가 모두 존재하는지 확인합니다.
  • 수강생은 거래 5건에 대해 매출·매입 감사절차 수행 결과와 발견사항 문구를 작성합니다.

전산감사 실습

같은 감사위험을 데이터 관점으로 바꾸어 원천 테이블, 로그, 마스터, 예외 조건을 활용합니다.

  • 매출 테이블, 출고 테이블, 전자세금계산서 테이블, 입금 테이블을 거래처코드와 문서번호로 연결합니다.
  • 매입은 발주, 입고, 세금계산서, 지급 데이터의 3-way 또는 4-way match를 수행합니다.
  • 기말 전후 거래를 전체 추출하여 출고일보다 매출일이 빠른 건, 입고일보다 매입일이 늦은 건을 필터링합니다.
  • 동일 거래처·동일 금액·동일 일자 거래의 중복 가능성을 조건식으로 탐색합니다.
  • 수강생은 매출·매입 데이터 플로우 차트와 예외 거래 분석표를 만듭니다.

일반감사 vs 전산감사 비교 포인트

구분일반 회계감사전산감사
컷오프 확인일반감사는 기말 전후 증빙을 표본으로 대조합니다.전산감사는 모든 거래의 일자 필드를 비교해 예외를 먼저 추출합니다.
실재성 확인원본 계약서와 외부증빙 확인이 중요합니다.출고·입고·세금계산서·입출금 데이터 간 연결 여부가 중요합니다.
업무 효율표본 수가 늘수록 수기 검토 시간이 급증합니다.규칙을 만들면 전체 거래를 반복적으로 재수행할 수 있습니다.

실습 데이터 예시

수업에서는 아래와 같은 필드를 가진 샘플 CSV 또는 엑셀 파일을 사용합니다. 데이터는 회사 실무 자료와 유사한 구조로 만들고, 일부 오류를 의도적으로 심어 비교 실습을 진행합니다.

  • SALES: invoice_no, customer_id, sales_date, ship_date, amount, vat
  • PURCHASE: po_no, vendor_id, receipt_date, invoice_date, amount
  • CASH_RECEIPT: customer_id, receipt_date, receipt_amount, bank_ref

수업 진행 흐름

  1. 이슈 읽기: 회계감사 시험형 문제 또는 현업 시나리오를 읽고 감사위험을 표시합니다.
  2. 일반감사 설계: 필요한 증빙, 표본 선정 기준, 인터뷰 질문, 조서 결론 문구를 작성합니다.
  3. 데이터 설계: 필요한 테이블과 필드를 정의하고, 누락되면 어떤 분석이 불가능한지 설명합니다.
  4. 예외 추출: 전체 모집단에서 규칙 기반 예외를 만들고 일반감사 표본과 비교합니다.
  5. 통합 결론: 증빙 확인 결과와 데이터 분석 결과가 서로 맞는지 확인한 뒤 최종 발견사항을 정리합니다.

수업 산출물

  • 매출·매입 컷오프 조서
  • 거래별 증빙 패키지 체크리스트
  • 전산감사 예외 거래 추출표
  • 3-way match 결과 요약
