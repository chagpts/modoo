# AuditSecu Academy

## 변경 사항
- Hero 배경 영상은 사이트 폴더의 상위 폴더에 있는 `4.mp4`를 사용합니다.
- 메인 커리큘럼 카드는 클릭 시 각 상세 과정 페이지로 이동합니다.
- `eyebrow` 문구와 `~개 세부 교육 페이지` 문구는 제거했습니다.
- `회계 데이터 이해`의 세부 교육 페이지를 일반 회계감사 실습과 전산감사 실습 비교 중심으로 확장했습니다.

## 실행 구조
```text
4.mp4
auditsecu_no_eyebrow/
  index.html
  css/
  js/
  pages/
```

`index.html`을 브라우저로 열면 됩니다.
