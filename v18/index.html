AuditSecu는 단순 데이터 대시보드가 아니라, 실제 회계·감사·내부통제 업무에서 검토해야 할 항목을 정리하고 감사 조서와 내부회계관리 보고서 초안까지 연결하는 업무형 플랫폼입니다.

Standard Review Flow From data to report
  1. 1데이터 수집계약서, 전표, 증빙, 승인 이력, ERP 로그, 권한표, 소스코드 업로드
  2. 2AI 분석OCR, 필드 추출, 회계처리 검토, 통제 기준 적용, 취약 코드 식별
  3. 3리스크 연결거래 오류, 승인 미비, 권한 남용, 재무제표 왜곡 가능성 분석
  4. 4산출물 생성검토 근거, 예외사항, 개선 권고, 감사 조서 및 내부회계 보고서 초안 제공

기업이 이해하기 쉬운 네 가지 업무 영역

회계 처리, 내부통제, 전산감사, 정보보안 점검을 재무보고 리스크 관점으로 연결합니다.

01

회계 문서 분석

계약서와 증빙에서 회계처리에 필요한 조건을 추출하고 전표·재무제표 반영을 검토합니다.

  • 대출·리스·매출 계약
  • AI OCR 및 조건 추출
  • 분개 후보 생성
02

ITAC 통제 점검

계산 로직, 승인 조건, 마감 기준, 시스템 입력값이 적절히 작동하는지 점검합니다.

  • 이자율 재계산
  • Cut-off 검토
  • 승인·마감 통제
03

ITGC·보안 점검

권한, 로그, 코드 취약점이 회계 데이터 변경 위험으로 이어지는지 확인합니다.

  • 권한 분리
  • 관리자 로그
  • 취약 코드 리뷰
04

감사 산출물 생성

검토 절차, 발견 사항, 근거 데이터, 개선 권고를 보고서 형태로 구조화합니다.

  • 전산감사 조서
  • 내부회계관리 보고서
  • 개선 과제 목록

보고서 초안: 계약서상 이자율과 ERP 입력값은 일치하나, 월말 발생이자 계산 검토와 마감 이후 전표 수정 승인 근거 확인이 필요합니다. 검토 절차와 발견사항은 전산감사 조서 및 내부회계관리 운영평가 문서로 자동 정리됩니다.

회계 시스템 보안 취약점이 재무제표에 미치는 영향 점검

회계 시스템 코드에서 Statement 기반 SQL 문자열 결합이 발견되면, AI는 SQL Injection 취약 가능성을 식별하고 해당 취약점이 권한 우회, 회계 DB 무단 변경, 재무상태표 왜곡 리스크로 연결될 수 있는지 감사 관점에서 평가합니다.

Risk Linkage재무보고 영향 연결

조회 화면 취약점이 권한 우회 및 회계 DB 변경 가능성으로 확대될 수 있는지 평가합니다.

Remediation통제 개선 권고

PreparedStatement 적용, 최소권한 계정, 변경관리, 로그 모니터링 강화를 제안합니다.

취약 예시Statement
String vendor = request.getParameter("vendor");
String status = request.getParameter("status");

Statement stmt = connection.createStatement();
String sql = "SELECT invoice_no, amount "
  + "FROM ap_invoice "
  + "WHERE vendor_name = '" + vendor + "' "
  + "AND payment_status = '" + status + "'";

ResultSet rs = stmt.executeQuery(sql);
개선 예시PreparedStatement
String sql = "SELECT invoice_no, amount "
  + "FROM ap_invoice "
  + "WHERE vendor_name = ? "
  + "AND payment_status = ?";

PreparedStatement pstmt =
  connection.prepareStatement(sql);
pstmt.setString(1, vendor);
pstmt.setString(2, status);

ResultSet rs = pstmt.executeQuery();

감사 관점 결론: 해당 취약점은 단순 개발 오류가 아니라 재무보고 데이터의 무결성 리스크로 분류됩니다. AuditSecu는 코드 취약점, DB 권한, 로그, 재무제표 계정 매핑을 함께 분석하여 ITGC 미비사항과 재무제표 왜곡 가능성을 보고서 형태로 정리합니다.

최종 결과물은 검토자가 바로 사용할 수 있는 문서입니다.

분석 화면에서 끝나지 않고, 감사·내부통제·보안 담당자가 후속 조치할 수 있는 형태로 산출물을 제공합니다.

01. 예외 항목 목록

검토가 필요한 거래, 통제 미비, 권한 예외, 코드 취약점을 위험도와 근거별로 정리합니다.

02. 감사 근거 패키지

원천 데이터, 계약서 추출값, 전표, 승인 이력, 로그, 코드 위치를 하나의 검토 단위로 묶습니다.

03. 보고서 초안

전산감사 조서, 내부회계관리 운영평가, ITGC·ITAC 개선 권고 보고서 초안을 생성합니다.
