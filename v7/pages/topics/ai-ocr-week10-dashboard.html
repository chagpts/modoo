10주차: 감사 대시보드

이상거래, 처리현황, 통제예외, 사용자별 업무량을 시각화합니다.

수업 목표

  • 10주차: 감사 대시보드의 감사 목적과 위험을 설명할 수 있습니다.
  • 전통적 감사 절차와 전산감사 절차를 구분해 조서화할 수 있습니다.
  • 실습 결과를 포트폴리오 산출물로 정리할 수 있습니다.

교육 내용

이상거래, 처리현황, 통제예외, 사용자별 업무량을 시각화합니다. 이 수업에서는 실제 감사인이 어떤 질문을 던져야 하는지, 전산감사 담당자가 어떤 데이터와 로그를 확인해야 하는지, 최종 조서에는 어떤 근거가 남아야 하는지를 단계별로 다룹니다.

실습 구성

  1. 매일 1~2시간 개발 학습 과제 수행
  2. 화면/DB/API/로그 중 해당 주차 기능 구현
  3. 테스트 케이스 작성과 오류 수정
  4. 주차별 구현 결과 GitHub 또는 포트폴리오 문서화

완성 산출물

수업 종료 후에는 체크리스트, 테스트 절차, 발견사항, 개선 권고안을 포함한 1~2페이지 분량의 교육용 감사 산출물을 완성합니다.

권장 학습 방식

개념 30% · 실습 50% · 조서/보고서 작성 20%

연결 직무

전산감사, IT감사, 내부회계관리, 회계자동화, 정보보안 감사
