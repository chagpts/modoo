악성 파일 업로드

증빙 업로드 기능에 웹셸, 매크로, 위장 확장자가 들어오는 케이스를 방어합니다.

수업 목표

  • 악성 파일 업로드의 감사 목적과 위험을 설명할 수 있습니다.
  • 전통적 감사 절차와 전산감사 절차를 구분해 조서화할 수 있습니다.
  • 실습 결과를 포트폴리오 산출물로 정리할 수 있습니다.

교육 내용

증빙 업로드 기능에 웹셸, 매크로, 위장 확장자가 들어오는 케이스를 방어합니다. 이 수업에서는 실제 감사인이 어떤 질문을 던져야 하는지, 전산감사 담당자가 어떤 데이터와 로그를 확인해야 하는지, 최종 조서에는 어떤 근거가 남아야 하는지를 단계별로 다룹니다.

실습 구성

  1. 공격 시나리오 이해
  2. 취약 설정 또는 취약 코드 식별
  3. 방어 통제와 탐지 로그 설계
  4. 보안 감사 체크리스트와 개선안 작성

완성 산출물

수업 종료 후에는 체크리스트, 테스트 절차, 발견사항, 개선 권고안을 포함한 1~2페이지 분량의 교육용 감사 산출물을 완성합니다.

권장 학습 방식

개념 30% · 실습 50% · 조서/보고서 작성 20%

연결 직무

전산감사, IT감사, 내부회계관리, 회계자동화, 정보보안 감사
