승인 우회 사고

 07

OCR API 남용과 비용 폭증

 07

배포 오류로 인한 통제 비활성화

백업 실패와 복구 불가

장애 발생 후 백업이 실패했거나 복구 테스트가 없던 문제를 보고서화합니다.

 07

ERP 인터페이스 불일치
