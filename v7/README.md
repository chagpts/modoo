# AuditSecu Academy V2

완전히 새로 만든 정적 학원 커리큘럼 사이트입니다.

## 실행 방법

1. 압축을 풉니다.
2. `index.html`을 브라우저로 엽니다.
3. 8단계 카드 또는 각 수업 카드를 클릭해 페이지 이동을 확인합니다.

## 구성

- `index.html`: 메인 페이지
- `pages/`: 8단계 상세 페이지
- `pages/topics/`: 77개 세부 교육 페이지
- `css/reset.css`, `css/style.css`: 공통 스타일
- `js/main.js`: 모바일 메뉴와 문의 폼 임시 저장

## 참고

문의 폼은 정적 사이트 확인용입니다. 실제 전송은 Supabase, Firebase, Formspree, 자체 서버 중 하나를 연결하면 됩니다.
