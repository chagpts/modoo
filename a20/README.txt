AuditSecu demo package

실행 방법:
1. 압축을 풉니다.
2. index.html을 브라우저로 엽니다.
3. 상단 메뉴 또는 첫 화면의 'AI 실습 랩 보기'를 클릭하면 audit-simulation-lab.html로 이동합니다.

포함 파일:
- index.html
- audit-simulation-lab.html
- assets/css/style.css
- assets/js/script.js

참고:
- index.html에는 배경 영상 4.mp4 경로가 남아 있습니다. 4.mp4 파일이 같은 폴더에 있으면 자동 재생되고, 없어도 CSS 배경으로 페이지가 표시됩니다.
- audit-simulation-lab.html은 데모용 CSS/JS를 자체 포함한 단독 페이지입니다.
