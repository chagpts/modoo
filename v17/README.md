# AuditSecu Academy

## 개요
이 패키지는 회계감사, 내부회계관리, 실습용 데이터셋 구축, AI OCR 회계 자동화, ITGC/ITAC, 전산감사 데이터 분석, 정보보안 감사 및 통합 감사 사례를 모듈형 교육과정으로 구성한 정적 웹사이트입니다.

## 주요 반영 사항
- Hero 영역은 사이트 폴더의 상위 경로에 위치한 `4.mp4` 파일을 배경 영상으로 사용합니다.
- 메인 교육과정 항목은 선택 시 각 과정 상세 페이지로 이동합니다.
- `eyebrow` 문구와 `~개 세부 교육과정` 문구를 제거하여 화면 구성을 간결하게 정리하였습니다.
- 회계 데이터 이해, 내부회계관리, AI OCR 회계 자동화, ITGC & ITAC 과정의 세부 교육과정을 실습 중심 콘텐츠로 확장하였습니다.
- 내부회계관리와 AI OCR 회계 자동화 사이에 `실습용 데이터셋 구축·검증` 과정을 추가하였습니다.
- 전체 문구를 교육기관 및 전문 컨설팅 사이트에 적합한 공식 문체로 정제하였습니다.

## 실행 구조
```text
4.mp4
전체폴더/
│  └─ details/
└─ a/
   ├─ index.html
   ├─ css/
   ├─ pages/
   └─ js/
```

사이트는 `a/index.html`을 브라우저에서 열어 실행합니다. 세부 교육과정은 각 과정 페이지에서 `details/...` 경로로 연결됩니다.
