# AuditSecu Website

깔끔하게 정리한 AuditSecu 랜딩페이지 프로젝트입니다.

## 파일 구조

```
auditsecu_web_project/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   └── img/
└── docs/
```

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## 구성

- 대출 계약서 기반 AI Audit Workbench 데모
- 회계 시스템 SQL Injection 취약점 점검 데모
- ITGC·ITAC, 내부회계관리, 전산감사 관점 메시지
- 반응형 랜딩페이지 CSS
