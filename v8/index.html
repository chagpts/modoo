AI OCR 회계 자동화

  • 자동 분개 승인 흐름
04

ITGC & ITAC

  • 퇴사자 계정 탐지
  • 운영 DB 접근 점검
  • 한도 초과 자동통제 테스트
05

전산감사 데이터 분석

  • 중복 지급 분석
  • 휴일·야간 전표 탐지
  • 특정 거래처 집중 분석
06

정보보안 회계 시스템 감사

  • 관리자 권한 검토
  • 비정상 로그인 탐지
  • 회계 데이터 다운로드 분석
07

종합 케이스 감사

  • 문제 상황 분석
  • 감사 증거 정리
  • 감사보고서 제출
08

커리어 & 포트폴리오

  • 프로젝트 산출물 정리
  • 이력서 문장 작성
  • 면접 질문 대비
