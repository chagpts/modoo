AuditSecu는 ITGC 및 ITAC 관점에서 전표, 증빙, 승인 이력, 권한표, ERP 접속 로그 등 주요 회계·IT 통제 데이터를 통합 분석하여 회계 오류, 이상거래, 승인 통제 미비, 접근권한 위험, 시스템 사용 이상 징후를 선별하는 AI 기반 내부통제·감사 업무 플랫폼입니다.

교육기관·커리어 과정

경영진·관리 책임자

String status = request.getParameter("status");

           + "FROM ap_invoice "
           + "WHERE vendor_name = ? "

PreparedStatement pstmt = connection.prepareStatement(sql);
pstmt.setString(1, vendor);
pstmt.setString(2, status);

ResultSet rs = pstmt.executeQuery();
Critical SQL Injection 가능성

사용자 입력값이 SQL 문자열에 직접 결합되어 회계 DB 조회 조건이 변조될 가능성이 있습니다.

ITGC 변경관리 통제 미비

운영 반영 전 보안 코드 리뷰와 취약점 점검 증적이 충분하지 않은 것으로 분류됩니다.

ITAC 재무 데이터 무결성 위험

조회 화면 취약점이 권한 우회로 이어질 경우, 승인되지 않은 회계 데이터 변경과 재무제표 왜곡 위험이 발생할 수 있습니다.

AI 보고서 초안
매입채무 조회 모듈에서 PreparedStatement가 아닌 Statement 기반 SQL 실행 로직이 확인되었습니다. 사용자 입력값이 바인딩 처리 없이 SQL 문자열에 결합되어 SQL Injection 위험이 존재하며, 해당 취약점은 단순 데이터 조회 위험을 넘어 회계 DB 권한 우회, 승인되지 않은 전표·채무 데이터 변경, 재무상태표 계정 왜곡으로 확대될 수 있습니다. PreparedStatement 적용, 입력값 검증, 최소권한 DB 계정 사용, 중요 테이블 변경 차단, 전표 변경 승인 워크플로우, 배포 전 정적분석 및 코드 리뷰 승인 절차 강화를 권고합니다. 본 사항은 전산감사 조서상 애플리케이션 보안 취약점 및 내부회계관리제도상 IT 일반통제·응용통제 보완 필요 항목으로 보고됩니다.

교육은 별도 상품이 아니라 플랫폼 도입을 위한 실무 Enablement입니다.
