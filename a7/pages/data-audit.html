06. 전산감사 데이터 분석

Certified Information Systems Auditor 관점의 IT 감사 절차를 회계 데이터 분석 실습으로 전환하는 과정

세부 교육과정

세부 과정을 선택해 바로 확인하세요.

06-01

감사계획과 데이터 요청 범위 설계

CISA식 감사계획을 회계 데이터 요청목록으로 전환합니다.

06-02

모집단 완전성 검증과 재계산

추출된 데이터가 원천시스템과 일치하는지 검증합니다.

06-03

SQL 기반 예외거래 탐지

감사인이 설명 가능한 SQL 규칙으로 오류 후보를 찾습니다.

06-04

로그 분석과 사용자 행위 추적

사용자 로그를 감사증거로 해석하는 방법을 익힙니다.

06-05

마스터 데이터 변경 분석

거래처·계정·품목 마스터 변경이 재무제표에 미치는 영향을 분석합니다.

06-06

접근권한 데이터 분석

권한 테이블을 분석해 업무분장 충돌과 과다권한을 찾습니다.

06-07

인터페이스·배치 데이터 대사

시스템 간 데이터 이동 과정의 누락과 중복을 점검합니다.

06-08

백업·복구와 감사 추적성 점검

데이터 분석 관점에서 백업과 복구 가능성을 검토합니다.

06-09

분석 결과 시각화와 보고

분석 결과를 감사인이 이해할 수 있는 리포트로 정리합니다.

06-10

데이터 분석 조서화와 품질검토

반복 가능한 감사 데이터 분석 조서를 완성합니다.
