학습 목표

증빙검사와 분석적절차를 OCR 추출값, 계정과목 추천결과, 이상 계정분류 탐지 모델로 비교합니다. 이 수업에서는 개념 설명에서 끝나지 않고, 실제 감사인이 남겨야 하는 증거와 개발자가 구현해야 하는 통제 포인트를 함께 정리합니다.

수업에서 다루는 데이터

  • 회계 전표, 증빙 이미지, 승인 이력, 사용자 권한표, 시스템 로그 중 해당 주제와 관련된 샘플 데이터
  • 일반 감사 조서 양식과 전산감사 분석 결과표
  • 위험 식별, 통제 테스트, 개선권고를 작성하기 위한 체크리스트

일반 감사 vs 전산감사 비교

일반 감사 접근

  • 증빙 원본, 계약서, 조회서, 승인 문서 등 표본 기반 증거를 확인합니다.
  • 감사인의 판단으로 위험을 식별하고 필요한 대체절차를 수행합니다.
  • 감사조서에는 질문, 검사, 재계산, 분석적절차 결과를 문서화합니다.

전산감사 접근

  • ERP 원장, 로그, OCR 결과, 승인 이력, 외부 데이터의 전체 모집단을 분석합니다.
  • SQL·Python·대사 규칙으로 예외 후보를 자동 탐지하고 재수행 가능하게 남깁니다.
  • 쿼리, 해시, 추출 기준, 결과 파일을 감사증거로 보관합니다.

실습 절차

  • 사례 배경과 재무제표 주장 또는 보안 위험을 정의합니다.
  • 필요한 데이터와 증거를 식별하고, 누락·오류·권한 문제를 점검합니다.
  • 감사 테스트 또는 개발 기능을 수행한 뒤 결과를 표준 조서로 정리합니다.
  • 발견사항을 위험등급별로 분류하고 개선권고를 작성합니다.

완성 산출물

  • 교육용 감사조서 1부
  • 데이터 분석 또는 통제 테스트 결과표 1개
  • 포트폴리오에 넣을 수 있는 요약 보고서 1부
