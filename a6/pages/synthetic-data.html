03. 실습용 데이터셋 구축·검증

내부회계관리 조서와 AI OCR 회계 자동화 사이에서, 실제 문서를 안전하게 다루는 데이터셋 구축·마스킹·태깅·합성·검증 실무를 학습합니다.

세부 교육과정

AI OCR 회계 자동화 시스템을 구축하기 전에 필요한 실습용 가상 데이터셋, 실제 템플릿 참조, 마스킹, 태깅, 정답 라벨, 실무 유사성 검증 과정을 모듈형 세부 페이지로 구성하였습니다.

03-01

데이터셋 구축 목적과 적법성 기준

교육·개발·감사 목적을 명확히 구분하고, 실제 문서 사용 가능 여부와 합성데이터 구축 원칙을 수립합니다.

03-02

민감정보 식별과 원본 데이터 진단

세금계산서, 영수증, 카드전표, 거래명세서에서 개인정보와 회사 내부정보가 어느 영역에 내재되어 있는지 식별합니다.

03-03

완전 합성 데이터 생성 설계

실제 값을 활용하지 않고 가상 회사·거래처·품목·금액·부가세·계정과목을 회계 규칙에 맞게 생성합니다.

03-04

실제 템플릿 참조와 가상값 삽입

실제 문서의 구조만 참고하고 값은 모두 가상으로 치환하여 실무 유사 문서를 작성합니다.

03-05

마스킹·가명처리·비식별 점검

실제 문서를 제한적으로 사용할 때 필요한 마스킹, 가명처리, 재식별 위험 점검 절차를 실습합니다.

03-06

태깅 기반 최소 데이터셋 설계

원본 이미지를 저장하지 않고 필요한 회계 판단 필드만 태깅해 데이터 최소화 원칙을 적용합니다.

03-07

OCR 이미지 합성과 노이즈 생성

깨끗한 합성 문서를 실제 스캔 문서처럼 흐림·기울어짐·그림자·부분 잘림을 넣어 테스트합니다.

03-08

정답 라벨 JSON과 전표 기대값 설계

Gemma가 추출해야 할 정답 JSON과 회계 전표 기대값 CSV를 설계해 자동 평가 기준을 작성합니다.

03-09

실무 유사성 검증 리포트

문서유형, 금액분포, 계정과목, 오류패턴, 예외거래가 실제 회계업무와 유사한지 검증합니다.

03-10

데이터셋 거버넌스와 반출통제

데이터셋의 생성·검토·배포·폐기·변경 이력을 관리하고 교육용 반출 기준을 문서화합니다.
